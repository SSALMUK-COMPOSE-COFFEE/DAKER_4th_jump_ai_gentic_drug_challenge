## 1. 항목별 내용 배치

### `<요약>` (0.5쪽)

> ✅ **확정 (2026-08-03): 3문단 압축.** 아래 4문단 안에서 **4번(정직한 한계)을 3번(검증)에
> 흡수**한다 → `문제 → 제안 → 검증과 그 한계`. PPV 10.7% 는 유지하되 독립 문단으로 세우지 않고
> "그래서 예측기가 아니라 트리아지 도구로 정의한다"는 결론과 한 호흡에 붙인다.
> 효과: 분량 −0.3쪽 + 마지막 인상이 "10.7%"가 아니라 설계 결정으로 남는다.
> ⚠ **압축 시 특이도(0.400 역방향 / 0.543 기권)를 지우지 말 것.** 항목 4 의 핵심 재료다.

원래의 4문단 구조 — **문단 순서가 Peer Review 30% 방어에 직결된다.**

1. **문제** — Phase 2 중단률 17.92% 는 Phase 1·3 의 1.4배이고, 최다 원인이 모집 실패(26.7%)다.
2. **제안** — 등록 시점 스냅샷만 입력해 전례 증거를 조립하고, 인용을 LLM 이 아니라 코드가 검증한다.
3. **검증** — 1,463건 블라인드 백테스트. 적응증 층화 AUC 0.632, 특이도(0.400 역방향 / 0.543 기권).
4. **정직한 한계** — PPV 10.7%. 예측기가 아니라 우선순위 판별 도구.

**여기에 "예측 정확도"를 쓰지 않는다.** 우리 주장은 예측이 아니다(§2).

✅ **해소 (2026-08-03) — 4번 문단은 3번에 흡수한다.** 전문가 평가(70%)에서는 한계 고지가 신뢰의
근거가 되지만, 동료 평가(30%)에서는 "AUC 0.632, PPV 10.7%"만 눈에 남을 수 있었다(다른 팀은
"AUC 0.9"를 낸다). 독립 문단을 없애 마지막 인상이 한계가 아니라 설계 결정으로 끝나게 하고,
분량도 0.3쪽 회수한다. 한계 자체는 삭제하지 않는다 — 항목 4·5 에서 온전히 서술한다.

| 판단 의존 결과의 처리 | 복합 사유 8.0% → 코호트 121 vs 152 양쪽 측정(0.632 vs 0.637), 두 값 함께 보고 |
| 오남용 방지 | 분야 3은 분자를 생성하지 않아 유해물질 위험이 **구조적으로 없다.** 대신 우리 도메인 위험: ① 리스크 점수 오용 → 점수 미제시 ② 특정 시험 폄훼 → 스폰서 신분 공격 금지, T3 강제 ③ 근거 없는 경고 → 인용 의무 |
| 한계 자기공개 | 종양 5개 적응증이 65.3% / 사유 분류 29.5% 미분류 / 코퍼스 편향 2.28배 / T3 가 맥락 왜곡을 못 잡음 |

### 항목 6. 본선 시연 시나리오 (0.75쪽) — 현재 0.5쪽, 여유 있음

지시문이 **"시각화"** 를 요구한다. 시연의 서사:

1. 실제 중단된 트라이얼의 v0 를 입력. **결과는 화면에 가려둔다.**
2. A1 이 감사 계획을 세우고 **"이 감사는 돌리지 않습니다"를 이유와 함께 표시** (Phase 1/2 케이스)
3. T1 계량 감사 — 검증 통과 피처와 참고 피처가 **시각적으로 구분**되어 표시
4. T2 전례 검색 — 시간축에 전례 배치, 컷오프 이후는 회색 처리
5. **A4 → T5**: 에이전트가 제안한 근거를 통계 검사가 기각하는 장면. 층화 AUC·음성 대조군 실시간 표시 ★
6. **A4 → T3**: 인용이 없거나 원문과 다른 공격을 기각하는 장면. 기각 사유별 카운터 ★
7. A6 교정안 → T1 재실행 → **일부 피처가 악화된 것을 에이전트가 스스로 지적** ★ 클라이맥스
8. 가려둔 정답 공개 — 실제 `whyStopped` 와 대조
9. 전향 예측 해시를 화면에 표시

**5·6·7이 본선 "오류를 스스로 인지하고 수정 10점"의 실물이다.** 성공 장면이 아니라
**에이전트가 자기 답을 스스로 깎는 장면**을 보여준다는 것이 차별점이다.

### 항목 7. API·GPU 소요 규모 (0.5쪽) — 현재 0.5쪽

`agent-architecture.md` §9 표를 그대로. 핵심 문장: **도구 계층 전체가 LLM 을 쓰지 않는다.**
외부 API 는 전부 무료·인증 불필요(CT.gov v2, PubMed, Europe PMC).
GPU 는 로컬 모델을 쓰지 않으므로 "불필요"라고 명시한다.
⚠ 실측 비용은 `Ledger.report()` 실행 후 채운다. **추정치를 쓰지 않는다.**

### 항목 8. 파급효과 (1.0쪽, 20점) — 현재 1.0쪽

### 분야가 바뀌어도 유효한 제약 (계속 지킬 것)

- **"바이오마커로 좁히는 것이 모집 실패의 교정안"은 쓸 수 없다.** 문헌이 반대 방향이다 —
  Bennette 2016 (*JNCI*): 표적치료는 낮은 등록에 **보호적**(OR 0.57), 조직검체 요구는
  위험요인이 **아니었다**(OR 1.26, CI 1 포함). 우리 코퍼스에서도 바이오마커 플래그가
  세 실패 유형 전부와 무관했다. → 단방향 조언 대신 **순효과 표**를 출력한다.
- **타겟 근거 점수로 효능 실패를 예측한다는 주장은 하지 않는다.** 음성 대조군 미통과
  (표적 0.354 vs "타겟 유명도" 대조군 0.348). Open Targets `overall score` 는 구성상
  **순환적**이다 — `clinical_precedence` 가 도달 최대 임상단계의 함수다.
  → 분야 3 단독 확정으로 이 축 자체가 제외되었으므로 **더 이상 위험 요인이 아니다.**
- ⚠ `field-decision.md` 가 보고한 **재현성 결함** — 동일 스크립트 2회 실행에서 표본이 최대 7건,
  AUC 가 0.03 흔들렸다(원인 미확인). 해당 스크립트가 폐기 대상이므로 제안서에는 영향이 없으나,
  **새 분석 스크립트를 쓸 때 같은 결함이 없는지 확인할 것.**
