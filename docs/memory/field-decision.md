## 1. 결론 한 줄

> **분야 4로 전환한다 (분야 3 主 · 분야 1 從).** 본선 30점의 첫 기준 "도출된 **가설**이
> 생물학적으로 타당한 근거를 갖췄는가"는 프로토콜 감사만으로는 제출물이 구조적으로 없고,
> 개입 약물명 → 타겟 → 적응증 근거의 역추적이 코퍼스 1,463건 중 **783건(53.5%)에서 실제로
> 동작함을 확인했으며**, 프로토콜 축(모집 실현성)과 생물학 축(가설 강도)이 **같은 방정식에서
> 만나는 정량적 접점**(FDA enrichment 표본수 비율 × 스크리닝 수율 × 우리 월 모집부담 벤치마크)이
> 존재하기 때문이다.

**단, 중대한 제약 하나를 함께 확정한다.**
타겟 근거 점수가 효능 실패를 **예측한다는 주장은 제안서에 쓰지 않는다.** 아래 §3.4에서
음성 대조군에 걸렸고 순환성(circularity)이 문서로 확인됐다. 분야 1 파트는 "**예측기**"가 아니라
"**근거를 인용해 제시하는 감사 모듈**"로만 선언한다. 이 구분을 흐리면 경쟁 밀도 오판을 반복한다.

문헌이 지지하는 것은 두 가지이고 서로 다른 층에 있다:
1. 바이오마커 선별은 **필요 표본수를 줄이고 Phase 2→3 성공률을 올린다** (BIO 46.3% vs 28.3%, FDA 16배).

즉 올바른 융합 서사는 "**두 축을 하나의 방정식에서 동시에 계산하고 트레이드오프를 숫자로 제시한다**"이다.
"바이오마커로 좁혀라"는 단방향 조언이 아니다. 이 방정식은 §4.2에 있다.

### 2.4 참고 — 우리가 폐기한 경쟁 밀도 피처에 대한 문헌의 시선

Bennette 2016은 **경쟁 시험을 낮은 등록의 최대 위험요인(OR 1.88)으로 보고**했다. 단 분모가
"**적격환자 1만명·년당** 경쟁 시험 수"다. 우리가 폐기한 버전은 정규화 없는 **원시 개수**였고
적응증 교란에 걸렸다(층화 AUC 0.463, `validated-numbers.md` §3.1). 문헌은 폐기가 **개념의 오류가
아니라 정규화의 부재** 때문일 가능성을 시사한다. → 본선에서 "적격환자 풀로 정규화한 재시도"를
가설로 세울 수 있으나, **예선 제안서에서는 폐기 판정을 유지한다** (재검증 전에 되살리면 같은 실수다).

## 3. Open Targets / 타겟 역추적 실현성 — 실제 호출 결과

### 3.1 API 생존·인증 (전부 실측)

```bash
curl -X POST https://api.platform.opentargets.org/api/v4/graphql \
  -H 'Content-Type: application/json' \
  -d '{"query":"{meta{apiVersion{x y z} dataVersion{year month}}}"}'
# → {"data":{"meta":{"apiVersion":{"x":"26","y":"6","z":"3"},"dataVersion":{"year":"26","month":"06"}}}}
```

- **인증 불필요, 무료.** GET은 400/500, **POST 필수** (`data-sources.md` 기록과 일치).
- API v26.6.3 / 데이터 릴리스 2026.06.
- **스키마가 바뀌었다.** `data-sources.md`의 예시는 통하지만, 아래는 **더 이상 존재하지 않는다**:
  `Drug.maximumClinicalTrialPhase` → `maximumClinicalStage`, `Drug.linkedTargets` → 삭제,
  `Drug.hasBeenWithdrawn` → 삭제. `synonyms`/`tradeNames`는 스칼라 리스트가 아니라
  `[DrugLabelAndSource!]!` 로 **하위 선택 필수** (`synonyms{label}`).
  → 1차 시도에서 이걸 몰라 전체 GraphQL 문서가 오류를 내고 **해석 성공률이 0%로 나왔다.** 수정 후 정상.

### 3.2 개입 약물명 → 타겟 역추적: **가능** (사내 코드명 포함)

```bash
# 1단계: 코드명으로 검색
-d '{"query":"{search(queryString:\"SAR408701\", entityNames:[\"drug\"]){hits{id name}}}"}'
# → {"hits":[{"id":"CHEMBL4298098","name":"TUSAMITAMAB RAVTANSINE"}]}

# 2단계: 작용기전 → 타겟
-d '{"query":"{drug(chemblId:\"CHEMBL4298098\"){name drugType maximumClinicalStage
     mechanismsOfAction{rows{mechanismOfAction actionType targets{id approvedSymbol}}}}}"}'
# → CEACAM5(ENSG00000105388) binding agent + Tubulin inhibitor(TUBB 계열 15개)
```

실측 확인된 코드명 해석: `SAR408701`→TUSAMITAMAB RAVTANSINE, `HM61713`→OLMUTINIB(→EGFR),
`CDP6038`→OLOKIZUMAB, `ALT-803`→NOGAPENDEKIN ALFA, `tarloxotinib bromide`→CHEMBL4297662.

### 3.3 타겟-적응증 근거 점수: **가능**

15개 적응증 전부 최상위 검색 히트가 정확했다 (`atopic dermatitis`→`MONDO_0004980` "atopic eczema",
`pancreatic cancer`→`MONDO_0005192` "exocrine pancreatic carcinoma" 처럼 **표기가 달라지므로
매핑을 코드에 고정**했다. `src/analysis/target_evidence_signal.py:DISEASE_ID`).

```bash
-d '{"query":"{disease(efoId:\"MONDO_0005233\"){associatedTargets(Bs:[\"ENSG00000146648\"])
     {rows{target{approvedSymbol} score datatypeScores{id score}}}}}"}'
```

실측 응답 (EGFR × NSCLC): `score 0.8884`,
`clinical 0.9960 / literature 0.9997 / genetic_association 0.9339 / somatic_mutation 0.9311 /
affected_pathway 0.8255 / genetic_literature 0.6079 / animal_model 0.2500`

|---|---|---|---|
| EGFR × NSCLC | 0.8884 | 0.9960 | 0.9339 |
| IL4R × 아토피 습진 | 0.6101 | 0.9843 | **0.0563** |
| CEACAM5 × NSCLC | 0.3988 | 0.6005 | (없음) |

`target(){associatedDiseases(Bs:)}` 로는 **0.8526**, `disease(){associatedTargets(Bs:)}` 로는
**0.8884** 를 반환했다. 직접/간접(indirect) 처리 차이로 추정되나 **원인 미확인**.
→ 한 방향으로만 조회하도록 코드에 고정해야 한다.

### 3.4 그런데 이 점수를 우리 백테스트에 쓸 수 있는가 — **부분적으로만, 그리고 아직은 아니다**

#### (a) overall score는 **구성상 순환적이다** (문서로 확인)

Open Targets 플랫폼 문서(platform-docs.opentargets.org/evidence)에 따르면
`clinical_precedence`(=ChEMBL) 근거 점수는 **도달한 최대 임상 단계의 함수**이고,
게다가 **조기 중단 시 중단 사유 분류로 감점**된다:

| 임상 단계 | 점수 | | |
|---|---|---|---|
| 미상/전임상 0.01 | Phase I 0.1 | Phase II 0.2 | Phase II/III 0.5 |
| Phase III 0.7 | 승인전 0.8 | 승인/Phase IV 1.0 | |

> "In Step 2, for those clinical trials that have stopped early, the score is down-weighted
> based on the classification of the reason to stop." — 'Negative' 또는 'Safety or side effects'
> 사유는 **0.5배 가중**.

**즉 우리가 예측하려는 라벨(중단 사유 분류)이 피처 안에 직접 들어 있다.**
overall score 기반 결과는 어떤 값이 나와도 **예측력의 증거가 아니다.** 폐기.

#### (b) 시점 정합성(point-in-time)이 확보되지 않는다

- `Disease.associationTimeSeries(ensemblId, isDirect, aggregationTypes, startYear, endYear)` 가
  **스키마에는 존재한다**(`year`, `associationScore`, `yearlyEvidenceCount`, `novelty` 필드).
  그러나 EGFR×NSCLC, IL4R×아토피, CEACAM5×NSCLC 3쌍 × 인자 조합 4가지 전부 **`count: 0`**.
  → 공개 API에서 **아직 비어 있다.** 향후 채워질지 **(미확인)**.
- 근거 행(`Disease.evidences`)의 날짜 필드 실측: `publicationYear`는 **europepmc에만 채워져 있고**
  (500건 표본에서 441/441), `clinical_precedence`는 `publicationYear` 없음·`studyStartDate` 있음(74/80),
  **유전 근거(eva 399건, clingen 1건, gwas_credible_sets)는 둘 다 없음**.
  → 유전 근거의 시점 재구성은 API 단독으로 **불가**.
- **대안은 확인했다.** EBI FTP에 Open Targets 아카이브 릴리스가 **16.04부터 26.06까지 49개** 존재하고
  association 파일이 배포된다 (`20.02/output/20.02_association_data.json.gz`,
  **802,954,533 바이트 ≈ 803 MB**; 26.03은 `association_by_datatype_direct/` 디렉터리 형식).
  → **시험 개시일 직전 릴리스로 점시점 스냅샷을 만들 수 있다.** 단 릴리스가 2016년부터이므로
  코퍼스 중 개시 2016년 이후 **635/1,463건(43.4%)**만 대상이 된다
  (그 부분집합: 완주 247 / 과학적 중단 49 / 모집실패 41).

#### (c) 음성 대조군에 걸렸다 — 이번 조사의 결정적 결과

`validated-numbers.md`가 요구하는 방식대로 대조군을 강제했다. 대조군은 **같은 타겟의
다른 14개 적응증에 대한 점수 중앙값** — 즉 "이 타겟이 이 적응증에 맞는가"를 완전히 버리고
"이 타겟이 애초에 근거가 많은 유명 타겟인가"만 재는 예측기다.

중단-과학적(효능·독성) vs 완주, **적응증 층화** AUC (**낮을수록** 근거 강한 쪽이 안전):

| 피처 | 적응증 층화 | 95% CI | 판정 |
|---|---|---|---|
| `ot_overall_max` | 0.354 | [0.27, 0.44] | **순환적이므로 폐기** (§3.4a) |
| `CONTROL_fame_overall` (적응증 무시) | **0.348** | [0.27, 0.42] | **표적 피처와 사실상 동일** |
| `ot_nonclinical_max` (clinical·literature 제외) | 0.414 | [0.34, **0.51**] | **CI가 0.5 포함 → 미달** |
| `CONTROL_fame_nonclinical` | 0.457 | [0.39, 0.53] | 신호 없음 |
| `ot_genetic_max` (genetic_association 단독) | 0.468 | [0.41, 0.53] | **신호 없음** |

- 순환성 없는 버전(`ot_nonclinical_max`)은 미층화 0.446 [0.36, 0.52]와 적응증 층화 0.414 [0.34, 0.51]에서
  **CI가 0.5를 포함**한다. 적응증+phase 0.390 [0.30, 0.48], 적응증+스폰서 0.395 [0.30, 0.49]에서만 통과.
  → 프로젝트의 채택 규칙("**모든** 층에서 CI가 0.5를 넘지 않을 때만 채택")에 **미달**.
- 유전 근거 단독은 **모든 집단 중앙값이 0.000** 이다 (완주·모집실패·과학적·경영 전부).
  Minikel 2024·Razuvayevskaya 2024가 쓴 바로 그 변수가 **우리 15개 적응증·이 타겟 집합에서는
  거의 비어 있다.** 문헌의 유전 근거 주장은 우리 코퍼스로 재현할 수 없다.

**특이도는 좋았다** — 타겟 근거 피처는 모집 실패에 **기권**한다:
`ot_nonclinical_max` 모집실패 vs 완주 = 0.495 [0.40, 0.59] (0.5 포함), `ot_genetic_max` = 0.508 [0.44, 0.58].
반면 우리의 확정 피처 월 모집부담은 모집실패 0.637이고 효능 실패에는 **역방향 0.407**이다.
→ **두 피처가 서로 다른 것을 재고 있다는 증거는 있다.** 이것이 융합의 구조적 근거이고,
"타겟 근거가 효능 실패를 예측한다"는 별개의 주장은 아직 성립하지 않는다.

**부작용 하나 더** — `ot_overall_max`는 **경영 중단**에도 발화한다 (적응증 층화 0.398 [0.33, 0.50],
적응증+phase 0.375 [0.29, 0.45]). C분류 기권 원칙과 충돌한다. 근거가 약한 프로그램이 포트폴리오에서
먼저 잘린다는 기계적 해석은 가능하지만, 우리 설계 원칙상 **특이도 위반**으로 기록해야 한다.

#### (d) 바이오마커 선별 플래그 — 코퍼스 안에서 아무 방향도 안 나온다

가설 B를 우리 데이터로 직접 검정했다 (`src/analysis/biomarker_enrichment.py`).
v0의 `eligibility_criteria`에서 분자 마커 + 상태어(mutation/positive/expression/genotype…)를
탐지: **1,463건 중 292건(20.0%)**. 적응증별 탐지율 검산이 통과한다 —
NSCLC 56.2% / 낭성섬유증 40.3% / SLE 32.3% / AML 29.8% ↔ 아토피피부염 **0.0%** / 2형당뇨 0.9% / 심부전 0.9%.

| 비교 (양성군 vs 완주) | 적응증 층화 AUC | 95% CI | 판정 |
|---|---|---|---|
| 중단-모집실패 | 0.483 | [0.45, 0.53] | 신호 없음 |
| 중단-과학적 | 0.511 | [0.47, 0.55] | 신호 없음 |
| 중단-경영 | 0.501 | [0.47, 0.54] | 신호 없음 |

- 즉 **바이오마커 선별이 효능 실패를 줄인다는 증거도, 모집 실패를 늘린다는 증거도 우리 데이터에 없다.**
- 부수 관측: 선별 시험은 포함기준 항목이 더 많다 (완주군 중앙값 **11개 vs 8개**, 모집실패군 **21개 vs 12개**)
  그러나 **월 모집부담은 차이가 없다** (완주군 3.33 vs 3.46명/월).
- **구조적 한계 — 이게 더 중요하다.** 우리 코퍼스는 **효능 성공을 측정할 수 없다.**
  "완주(COMPLETED)"는 1차 평가변수 달성을 의미하지 않는다. 따라서 BIO 보고서의 "Phase 2→3 성공률"과
  우리 라벨은 **다른 것**이고, 문헌 주장을 우리 데이터로 검증하는 것은 원리적으로 불가능하다.
  → 분야 1 파트를 검증하려면 **새 라벨이 필요하다** (§4.3).

#### (e) 재현성 문제 (실측, 원인 미확인)

동일 스크립트를 2회 실행했을 때 총 역추적 건수는 **783건으로 동일**했으나, 집단별 표본이
최대 7건 흔들렸다 (중단-과학적 71 ↔ 78, 모집실패 58 ↔ 60) 그리고 AUC가 소수 둘째 자리에서 이동했다
(0.327 ↔ 0.354). OT `search`의 퍼지 순위 비결정성 또는 일시적 API 실패로 추정하나 **(미확인)**.
→ **해석 결과를 파일로 고정(캐시)하지 않으면 숫자를 인용할 수 없다.** 본선 필수 작업.

#### (f) API 버그로 보이는 것 (실측)

`Disease.evidences`의 `datasourceIds` 필터가 일부 데이터소스에서 동작하지 않는다.
IL4R × 아토피 습진을 **무필터**로 조회하면 `gwas_credible_sets` 1건, `clinical_precedence` 80건이

→ 서버 필터를 믿지 말고 **클라이언트에서 걸러야 한다.**

## 4. 권고 설계 — 분야 3 골격에 분야 1을 어디에 어떻게 끼우는가

### 4.1 선언 방식

- 선택분야: **분야 4 (융합)**. 제안서 본문 첫 줄에 **"분야 3을 주축으로 분야 1을 결합"** 을 명시.
- 에이전트가 답하는 질문을 **하나로** 유지한다: *"이 프로토콜은 왜 실패할 것인가."*
  융합은 **답의 두 축**이지 문제가 둘인 게 아니다. 이 문장이 예선 "필요성·문제정의 20점"의
  초점 흐려짐 위험을 막는 방어선이다.
- 두 축의 이름을 고정한다:
  - **R축 (Recruitability)** — 모집 실현성. 확정 피처 월 모집부담(적응증 층화 AUC 0.637, CI 0.568–0.705).
  - **H축 (Hypothesis)** — 타겟-적응증 가설 강도. 근거 인용 기반, **예측 성능 주장 없음**.

### 4.2 두 축이 실제로 만나는 지점 — 이게 융합의 정당성이다

교정 단계에서 두 축은 **한 방정식**에서 만난다. 심사위원이 "왜 융합이냐"고 물을 때의 답:

```
필요 표본수 N_enriched  =  f(효과크기, 마커 유병률 p)      ← FDA enrichment Table 1 (p=25%, 마커음성 효과 0 → 미선별 대비 1/16)
스크리닝 필요수 S       =  N_enriched / (p × 검사성공률 × 임상적격률)   ← NCI-MATCH 실측: 5,954 스크리닝 → 17.8% 배정
월 모집부담 재계산      =  S / 계획기간                     ← 우리 벤치마크: 완주군 3.37명/월, 모집실패군 1.50명/월
```

에이전트의 출력은 단방향 조언이 아니라 **순효과 표**다:

> "포함기준에 EGFR 변이를 넣으면 필요 등록수는 300 → 80명으로 줄어듭니다(FDA enrichment 표본수 비율,
> 유병률 가정 25%). 그러나 스크리닝은 450명이 필요해지고 월 모집부담이 2.1 → 5.6명/월로 올라갑니다.
> 같은 적응증 완주 시험의 중앙값은 3.37명/월, 모집에 실패한 시험은 1.50명/월입니다.
> 이 교정안은 **가설 강도를 올리는 대신 모집 실현성을 완주군 범위 밖으로 밀어냅니다.**"

이 출력은 **분야 3 단독으로는 만들 수 없고 분야 1 단독으로도 만들 수 없다.**
그리고 §2.3의 문헌 정정(조직검체 요구가 모집 실패 위험요인이 **아니었다**, Bennette OR 1.26)이
"그러니 무조건 위험하다"는 과장을 막아준다 — 에이전트는 **계산하고 제시하되 단정하지 않는다.**

### 4.4 4주(2026-09-07 ~ 10-02)에 가능한가 — **조건부 가능**

전제: 분야 1 파트를 **read-only 근거 감사**로 못 박는다. **신규 타겟 발굴·약물 재창출 후보 생성·
분자 생성은 범위에서 제외.** 그러면 이미 동작하는 코드가 출발점이다.

| 예비 | 4일 | |

합계 약 28일 중 **분야 1 증분이 약 12–15일**. **가능하지만 여유가 없다.**

### 4.6 만약 분야 3을 유지한다면 (기각한 대안, 방어 방법 기록)

- 본선 30점의 두 기준은 ①"도출된 **가설·분자 구조**가 생물학·화학적으로 타당한 근거" ②"기존 방식
  대비 혁신성"이다. **②는 분야 3 단독으로 정면 공략 가능**하다 (`history/0` 블라인드 백테스트,
  전향 예측 해시 커밋). 구조적으로 비어 있는 것은 **①뿐**이다. 배점의 내부 분할은 공개되지 않았으므로
  "30점 전부를 잃는다"는 표현은 과장이고, **①에 해당하는 몫을 잃는다**가 정확하다 (분할 비율 **(미확인)**).
- ①의 우회 논리: "가설"을 **실패 원인 가설**로 재정의하고, 기전적 근거(모집 실패의 인과 경로)와
  전례 NCT 인용으로 방어한다. **약점: 심사 기준이 "생물학·화학적으로" 라고 못 박고 있어서
  프로토콜 결함 가설은 이 수식어를 만족하지 못한다.** 심사위원이 학계 인사라는 점에서
  이 반론은 즉시 나올 가능성이 높다.
- 결론: 유지도 가능하지만 **가장 배점이 큰 항목의 절반을 자발적으로 포기하는 선택**이다.
  전환 비용(§4.4, 12–15일)이 4주 안에 들어오므로 유지를 권하지 않는다.

## 5. 위험과 미확인 사항

### 5.1 확인된 위험 (근거 있음)

1. **overall association score는 순환적이다.** OT `clinical_precedence` 점수 = f(도달 최대 임상단계,
   중단 사유 분류). 우리 라벨이 피처에 들어 있다. → 백테스트에서 **사용 금지**. (문서 근거 §3.4a)
2. **순환성 없는 버전은 채택 기준에 미달한다.** `ot_nonclinical_max` 적응증 층화 0.414 [0.34, 0.51].
   → 제안서에 **예측 AUC를 쓰지 않는다.**
3. **음성 대조군 미통과.** 적응증을 완전히 무시하는 "타겟 유명도" 대조군이 0.348 [0.27, 0.42]로
   표적 피처 0.354 [0.27, 0.44]와 사실상 같다. → "**타겟-적응증 적합도**를 잰다"는 주장 금지.
   말할 수 있는 것은 "타겟의 근거 총량"까지다.
4. **유전 근거 datatype이 우리 코퍼스에서 거의 비어 있다** (전 집단 중앙값 0.000).
   Nelson/Minikel/Razuvayevskaya의 변수를 우리 데이터로 재현할 수 없다.
5. **바이오마커 선별 플래그는 어느 실패 유형과도 연관되지 않았다** (3개 비교 전부 CI가 0.5 포함).
   → "바이오마커로 좁히면 좋아진다"를 우리 데이터 근거로 쓸 수 없다. 문헌 근거로만 인용.
6. **코퍼스는 효능 성공을 측정할 수 없다.** COMPLETED ≠ 1차 평가변수 달성.
   → H축 검증에는 새 라벨(Phase 3 후속)이 필수이고, 그 라벨은 아직 수집되지 않았다.
7. **역추적 재현성 결함.** 동일 코드 2회 실행에서 집단 표본이 최대 7건, AUC가 0.03 흔들렸다.
   원인 미확인. 캐시 고정 전에는 어떤 숫자도 인용 불가.
8. **적응증 커버리지 편차가 크다.** 낭성섬유증 36% / ALS 37% vs NSCLC 76%.
   H축을 전 적응증에 균일 적용하면 저커버리지 영역에서 침묵하는 감사가 된다.
9. **경영 중단(C분류)에 대한 특이도 위반.** `ot_overall_max`가 경영 중단에도 발화
   (적응증+phase 0.375 [0.29, 0.45]). 기권 원칙과 충돌.
10. **선행연구 리스크.** Razuvayevskaya 2024 (*Nat Genet*)가 "중단 사유 NLP 분류 × 유전적 근거"를
    28,561건 규모로 이미 발표했다. 차별점을 명시해야 한다 —
    ① 우리는 **등록시점 v0 스냅샷**만 입력으로 쓰는 블라인드 설계(그들은 사후 통계 분석),
    ② 우리는 **프로토콜 계량 감사와 교정 루프를 가진 에이전트**(그들은 논문),
    ③ 우리는 **R축과 H축의 트레이드오프를 계산**(그들은 연관성 추정).
11. **문헌 수치 중 2차 인용에 의존하는 항목이 있다.** Harrison 2016·Arrowsmith 2011의
    실패 사유 비율은 NRDD 1쪽 기사로 원문 미확보. 제안서에 쓸 때 **2차 인용임을 밝히거나
    Hwang 2016(전문 확인, Phase 3)으로 대체**할 것.
12. **BIO 보고서 수치의 세대 차이.** 바이오마커 LOA는 구판 25.9% → 신판 **15.9%**로 반감했다.
    구판 인용은 오도. 그리고 신판에서 **Phase 1에서는 효과가 없다**(52.4% vs 52.0%).
13. **FDA enrichment Table 1은 2012년 초안에서 확인**했다. 2019년 최종본이 동일한지 (미확인).

### 5.2 미확인 사항 (`(미확인)` 목록)

- **(미확인)** 분야별 본선 선발 쿼터·가중 존재 여부. 규정 문서에 언급 없음 → 게시판 질의 대상.
- **(미확인)** `associationTimeSeries`가 향후 데이터로 채워질지. 현재 3쌍 전부 `count: 0`.
- **(미확인)** 같은 타겟-질병 쌍의 점수가 `target→disease`(0.8526)와 `disease→target`(0.8884)에서
  다른 이유. 직접/간접 처리 차이로 추정.
- **(미확인)** `datasourceIds` 필터가 일부 데이터소스에서 0건을 반환하는 원인 (API 버그로 추정).
- **(미확인)** 역추적 재현성 흔들림의 원인 (OT search 순위 비결정성 vs 일시적 실패).
- **(미확인)** Phase 3 후속 라벨의 우측 절단 규모. 2019~2020년 개시 시험은 후속 Phase 3가
  아직 없을 수 있다 (코퍼스의 205건이 2019–2020 개시).
- **(미확인)** Phase 3 후속 라벨이 스폰서 자금력의 대리변수가 아닌지. 산업 vs 학술 층화 필요.
- **(미확인)** FDA 2019 최종 guidance의 Table 1 유지 여부.
- **(미확인)** Cook 2014 "Phase 2 실패의 65%가 효능 부족, 상당수는 타겟 이해 부족" 원문.
  **확인 전 인용 금지.**
- **(미확인)** 아카이브 릴리스 파싱 실작업 시간. 803MB×N을 numpy 없이 스트리밍 파싱하는
  비용을 실측하지 않았다.
- **(미확인)** 바이오마커 선별 정규식의 정밀도·재현율. 적응증별 탐지율 검산(NSCLC 56% ↔ 아토피 0%)은
  통과했으나 수동 라벨과 대조하지 않았다. 1차 시도에서 `MET` 411건·`FUS` 349건·`ANA` 115건의
  대량 오탐이 있었고(대소문자 무시 + 단어 경계 없음: "…subjects who **met**", "in**fus**ion",
  "**ana**lysis") 이를 고쳐 292건으로 내렸다. **같은 종류의 잔존 오탐 가능성을 배제하지 못한다.**

### 5.3 이 결정을 뒤집어야 하는 조건

1. 점시점 스냅샷으로 재계산한 H축이 **여전히 대조군을 못 이기면** → H축은 "근거 제시 모듈"로만
   남기고 **예측 기능을 제안서·시연에서 완전히 제거**한다 (분야 4 선언은 유지 가능 — 30점 요구는
   근거 제시이므로).
2. Phase 3 후속 라벨이 **스폰서 유형의 대리변수로 판명되면** → 라벨 폐기, `design-v2.md` §2.1의
   적격기준 개정 횟수와 같은 처리(공변량으로만 사용).
3. 역추적 캐시를 고정해도 재현성이 확보되지 않으면 → H축 수치 전면 비인용.
