## 공개 게시판용 (1~3번)

**제목**: 예선 제안서 양식 및 분량 규정 확인 요청 (3건)

안녕하세요. 예선 제안서 작성 중 규정 확인이 필요한 사항 3건을 문의드립니다.

**1. 제안서 양식 2종 중 어느 것을 기준으로 하나요?**

DAKER 대회 페이지 [데이터] 탭의 `[데이콘]AI_신약개발_경진대회_제안서.hwpx`는 **8개 항목**이고,
KHIDI 공고문 첨부의 `★(붙임)제안서.hwpx`는 **6개 항목**입니다. 두 파일의 차이는 DACON판에만
있는 다음 2개 항목입니다.

- 5. AI 활용 투명성 및 연구 윤리
- 7. API 및 GPU 관련 예상 소요 규모

예선 평가표에 "연구 윤리 및 완성도 10점"이 있어 DACON판(8항목)이 기준이라고 판단했으나,
공식 확인을 부탁드립니다. **KHIDI판(6항목)으로 제출한 경우 연구윤리 항목을 어디에 서술해야
하는지도 함께 알려주시면 감사합니다.**

**2. "10쪽 이내"에 표지·목차·요약이 포함됩니까?**

양식에 `<요약>` 섹션이 본문 앞에 있는데, 이것과 표지·목차가 10쪽에 포함되는지 확인 부탁드립니다.
또한 "첨부문서 등 기타 부분은 제외"에서 **참고문헌 목록과 도표가 첨부에 해당하는지** 알려주시면
감사합니다.

**3. 함초롬돋움 13pt·줄간격 130% 규정의 적용 범위가 어디까지입니까?**

양식에는 `<요약>`이 13pt/130%, 본문 계층(`□`,`◦`,`-`)이 13pt/160%, `※`가 11pt/130%로
더미 텍스트에 박혀 있습니다. **표 안의 텍스트와 도표 캡션에도 이 규정이 적용되는지**,
그리고 규정과 다른 서식을 쓰면 감점 사유인지 확인 부탁드립니다.

감사합니다.

## 비공개 문의용 (4번)

**제목**: 지식재산권 귀속 조항 적용 우선순위 확인 요청

안녕하세요. 예선 제안서 제출 전 IP 귀속 범위를 확인하고자 합니다.

KHIDI 공고문의 지식재산권 조항과 DAKER 플랫폼 참가 동의사항의 해당 조항이 서로 다르게 읽히는
부분이 있습니다. 다음 3가지에 대해 **어느 문서의 조항이 우선 적용되는지** 알려주시면 감사합니다.

1. **소스코드** — 참가팀이 대회 기간 중 작성한 코드의 저작권 귀속 및 대회 종료 후 공개·상업적
   활용 가능 여부
2. **모델 가중치·학습 데이터** — 참가팀이 구축한 데이터셋과 파인튜닝 결과물의 귀속
3. **특허** — 수상팀 후속 지원에 "특허 출원"이 명시되어 있는데, 이때 출원인·발명자 및
   지분 구조가 어떻게 되는지

저희 팀은 공개 데이터베이스(ClinicalTrials.gov 등)를 가공해 데이터셋을 구축하고 있어,
**대회 종료 후 해당 데이터셋과 코드를 오픈소스로 공개할 수 있는지**가 설계 결정에 영향을 줍니다.
가능한 범위에서 답변 부탁드립니다.

감사합니다.
