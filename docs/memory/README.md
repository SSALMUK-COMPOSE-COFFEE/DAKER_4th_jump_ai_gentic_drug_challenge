## 갱신 규칙

- **추측과 확인된 사실을 섞지 말 것.** 확인 안 된 항목은 `(미확인)` 명시.
- **라벨을 새로 만들면 반드시 기각 검증을 먼저 돌린다.** 라벨 4개 중 2개, 피처 여러 개가 실측에서 죽었다.
- **음성 대조군 없이 통과 판정하지 말 것.** 경쟁 밀도를 그렇게 잘못 통과시켰다.
  적응증 라벨만 쓰는 대조 예측기(0.722)를 넘는지 항상 확인한다.
- **층화하지 않은 AUC 를 결론으로 쓰지 말 것.** 미층화 0.678 → 적응증 층화 0.472 로 무너진 전례가 있다.
- 수치를 고치면 `validated-numbers.md` / `scale-and-value.md` 를 먼저 고치고, 코드에 하드코딩된
  값(`pipeline.FEATURE_STATUS`, `SCOPE_NOTICE`)을 함께 갱신한다.
